# Банкротные торги → канал @torgi_vrn_ss

Скрипт `torgi_monitor.py` каждый день в 10:00 ищет на банкротных торгах легковые
машины, которые на публичном предложении могут уйти дешевле рынка более чем на
50%, отсеивает битые/проблемные и публикует остальные в канал.

## Как это работает (по шагам)

1. **Сбор лотов**
   - **ЦДТ** (torgi.cdtrf.ru) — через их API: банкротные торги, категория
     «Легковой транспорт», форма «Публичное предложение», статусы «Торги
     объявлены / Приём заявок / Идут торги». По каждому лоту открывается
     карточка и берётся **график снижения цены**: первая цена = начальная,
     последняя = минимальная (конечная).
   - **МЭТС** (m-ets.ru) — через форму поиска: «Легковой автомобиль»,
     «Банкротство», «Публичное предложение», статусы «Объявленные / Приём
     заявок / Проведение». Из карточек берутся текущая и минимальная цена,
     начальная — со страницы лота.
2. **Марка, модель, год** вытаскиваются из текста лота (функция `parse_car`).
   Если распознать не удалось — лот пропускается.
3. **Рыночная цена** — по всей России, по Drom. Из текста лота достаются
   объём двигателя, мощность, коробка (АКПП/МКПП) и пробег (`parse_specs`),
   из VIN — год выпуска, если в тексте его нет (`parse_vin`). На Drom берутся
   до 40 объявлений той же марки/модели/года (с тем же объёмом двигателя), и из
   них выбираются похожие: объём ±0.1 л, мощность ±10%, та же коробка, пробег
   от 0.5× до 1.5× (+30 тыс. км). Если похожих меньше 3 — условия ослабляются
   по очереди: пробег → мощность → коробка → объём. Рыночная цена = медиана
   похожих. В посте пишется, по каким параметрам шло сравнение.
   Кэш страниц Drom: `data/torgi_market_cache.json` (обновляется сам, если старше `MARKET_CACHE_HOURS` = 12 ч).
4. **Отбор**: год выпуска не раньше `MIN_YEAR` (2010), лоты без распознанного года публикуются с пометкой «год не указан»; минимальная цена < `MAX_RATIO` × рыночной (сейчас 0.5).
   Отбрасываются доли («1/2 доли») и лоты дешевле `MIN_RATIO` (5%) от рынка.
5. **Отсев битых**: если в описании есть слово из `BAD_PATTERNS` (битый, ДТП,
   не на ходу, пожар, неисправен, коррозия, без ПТС и т.д.) — лот не
   публикуется. В логе видно, какое слово сработало.
6. **Публикация**: всё подходящее, чего ещё не было в канале, сортируется по
   скидке (самые выгодные первыми) и выкладывается пачками по `BATCH_SIZE` (20)
   с паузой `BATCH_PAUSE_MIN` (15 мин) между пачками.
   Опубликованное запоминается в `data/torgi_posted.json` и не повторяется.

## Где что менять

Все настройки — в блоке `НАСТРОЙКИ` в начале `torgi_monitor.py`:

| Что | Переменная |
|---|---|
| Порог скидки (0.5 = >50%, 0.4 = >60%) | `MAX_RATIO` |
| Размер пачки / пауза между пачками | `BATCH_SIZE`, `BATCH_PAUSE_MIN` |
| Слова, по которым лот считается битым | `BAD_PATTERNS` |
| Фразы-исключения («без повреждений») | `GOOD_PHRASES` |
| Минимальный год выпуска (сейчас 2010) | `MIN_YEAR` |
| Включить/выключить площадку | `USE_CDT`, `USE_METS` |
| Текст поста | функция `caption()` |
| Сколько страниц Drom брать для сравнения | `DROM_PAGES` |
| Правила «похожести» объявлений | функция `_similar()` |
| Время запуска | `com.user.torgi.plist` → `Hour` / `Minute` |

Токен бота — `TORGI_BOT_TOKEN` в `.env`, канал — `TORGI_CHAT_ID` (по умолчанию `@torgi_vrn_ss`).


## Файлы с результатами (`data/`)

- `torgi_deals.json` — все лоты ниже рынка >50% (до отсева битых)
- `torgi_clean.json` — после отсева битых (это и публикуется)
- `torgi_posted.json` — что уже опубликовано (id лота → номер сообщения в канале)
- `torgi.log` — лог ежедневных запусков

## Ограничения

- Рыночная цена не учитывает комплектацию и состояние; если в лоте не указаны
  двигатель/пробег — сравнение только по марке/модели/году.
- VIN не пробивается по базам (ГИБДД с капчей, Автотека платная) — из него
  берётся только год выпуска.
- Битые отсеиваются только если это написано в описании. На ЦДТ описание
  часто короткое — смотрите фото и документы лота.
- Компьютер должен быть включён (если спал в 10:00 — запуск после пробуждения).
